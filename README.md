# Журнал учеников
Простая консольная система управления студенческим журналом на языке Go, позволяющая вести учет студентов и их оценок.
___
## Функциональность
Основные возможности:
- Управление студентами
- Добавление новых студентов (ФИО)
- Удаление существующих студентов
- Просмотр списка всех студентов
- Работа с оценками
- Ввод оценок (от 1 до 5) для каждого студента
- Расчет среднего балла студентов
- Фильтрация студентов по среднему баллу
- Сохранение данных
- Cохранение данных в JSON-файл
- Загрузка данных из файла
## Использование
Главное меню:  
- Создать ученика - добавление нового студента в систему
- Удалить ученика - удаление студента из системы
- Ввести оценку - добавление оценок для выбранного студента
- Вывести средний балл - просмотр статистики успеваемости
- Сохранить в файл - принудительное сохранение данных
- Получить из файла - загрузка данных из файла
- Выход - завершение работы программы  

Работа со средним баллом:
- Общий средний балл всех студентов
- Студенты с средним баллом выше 4.0
- Студенты с средним баллом ниже 4.0
- Средний балл конкретного студента
___
## Основные функции программы
**SaveToFile(students map[int]string, journal map[int][]int)**

Назначение: Сохраняет данные студентов и журнала оценок в JSON-файлы.  
Параметры:
- students - map с ID студентов и их ФИО  
- journal - map с ID студентов и их оценками  

**LoadFromFile() (map[int]string, map[int][]int, error)**

Назначение: Загружает данные студентов и журнала из JSON-файлов.  
Возвращаемые значения:
- map[int]string - данные студентов
- map[int][]int - журнал оценок
- error - ошибка загрузки

**fileExists(filename string) bool**

Назначение: Проверяет существование файла.  
Параметры:
- filename - имя проверяемого файла
Возвращаемые значения:  
- bool - true если файл существует, false если нет

**getName() string**

Назначение: Читает ФИО студента из консоли.  
Возвращаемые значения:  
- string - полное ФИО студента

**SortKeys(Map map[int]string) []int**

Назначение: Сортирует ключи map по возрастанию.  
Параметры:
- Map - map с целочисленными ключами 

Возвращаемые значения:
- []int - отсортированный слайс ключей

**printStud(students map[int]string)**

Назначение: Выводит отсортированный список студентов в консоль.  
Параметры:
- students - map с ID студентов и их ФИО


**findKeyByValue(data map[int]string, value string) int**

Назначение: Находит ключ по значению в map.  
Параметры:
- data - map для поиска
- value - искомое значение

Возвращаемые значения:
- int - найденный ключ или 0 если не найден  


**averMark(students map[int]string, journal map[int][]int, name string) float64**

Назначение: Вычисляет средний балл студента.  
Параметры:
- students - map с данными студентов
- journal - map с оценками
- name - ФИО студента

Возвращаемые значения:
- float64 - средний балл студента
