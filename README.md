# Журнал учеников
Простая консольная система управления студенческим журналом на языке Go, позволяющая вести учет студентов и их оценок.
___
## Функциональность
Основные возможности:
- Управление студентами
- Добавление новых студентов (ФИО)
- Удаление существующих студентов
- Просмотр списка всех студентов
- Работа с оценками
- Ввод оценок (от 1 до 5) для каждого студента
- Расчет среднего балла студентов
- Фильтрация студентов по среднему баллу
- Сохранение данных
- Cохранение данных в JSON-файл
- Загрузка данных из файла
## Использование
Главное меню:  
- Создать ученика - добавление нового студента в систему
- Удалить ученика - удаление студента из системы
- Ввести оценку - добавление оценок для выбранного студента
- Вывести средний балл - просмотр статистики успеваемости
- Сохранить в файл - принудительное сохранение данных
- Получить из файла - загрузка данных из файла
- Выход - завершение работы программы  

Работа со средним баллом:
- Общий средний балл всех студентов
- Студенты с средним баллом выше 4.0
- Студенты с средним баллом ниже 4.0
- Средний балл конкретного студента
___
## Основные функции программы
**(`*`Journal) SaveToFile(filename string)**

Назначение: Сохраняет весь журнал (список студентов с их оценками) в один JSON-файл.  
Параметры:
- filename — имя файла для сохранения (например, "journal.json")

**LoadFromFile(filename string) (`*`Journal, error)**

Назначение: Загружает журнал из JSON-файла.  
Параметры:
- filename — имя файла для загрузки

Возвращаемые значения:
- *Journal — указатель на загруженный журнал с данными студентов
- error — ошибка, если файл не найден, повреждён или не может быть десериализован

**(`*`Journal) addStudent(name string)**

Назначение: Добавляет нового студента в журнал.  
Параметры:
- name — полное ФИО студента

**(`*`Journal) removeStudent(id int) bool**

Назначение: Удаляет студента по его ID.  
Параметры:
- id — идентификатор студента  

Возвращаемое значение:
- bool — true, если студент успешно удалён; false, если не найден

**(`*`Journal) addMark(id, mark int) bool**

Назначение: Добавляет оценку студенту.  
Параметры:
- id — ID студента
- mark — оценка (должна быть от 1 до 5)
Возвращаемое значение:
- bool — true при успешном добавлении, false при ошибке (некорректная оценка или студент не найден)

**(`*`Journal) averageMark(id int) (float64, bool)**

Назначение: Вычисляет средний балл студента по его ID.  
Параметры:
- id — ID студента

Возвращаемые значения:
- float64 — средний балл (округляется при выводе)
- bool — true, если у студента есть оценки и он существует; иначе false

**(`*`Journal) printStudents()**

Назначение: Выводит отсортированный по ID список всех студентов.  

**getName() string**

Назначение: Считывает из консоли три слова (имя, фамилию, отчество) и объединяет их в полное ФИО.  
Возвращаемое значение:
- string — строка вида "Иванов Иван Иванович"
